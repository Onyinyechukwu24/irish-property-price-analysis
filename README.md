# Irish Residential Property Price Analysis

## Project Overview

This project focuses on exploring and analysing residential property prices in Ireland using the R programming language.

The study aims to identify trends, patterns and relationships within the Irish housing market through data exploration, data preparation and statistical analysis.

## Research Objectives

- Examine changes in residential property prices over time.
- Compare property prices across Irish counties.
- Investigate differences between new and second-hand properties.
- Identify missing values, duplicates and unusual observations.
- Explore relationships between selected dataset features.
- Apply categorical encoding and Principal Component Analysis (PCA).

## Research Questions

1. How have residential property prices changed over time?
2. Which counties have the highest and lowest property prices?
3. Are there differences between new and second-hand property prices?
4. What relationships exist between the selected variables?
5. What patterns can be identified using PCA?

## Dataset

**Proposed dataset:** Irish Residential Property Price Register.

**Primary source:** https://www.propertypriceregister.ie/

The final dataset, its source details and its characteristics will be documented following data collection and verification.
